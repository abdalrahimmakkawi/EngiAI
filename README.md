# EngiAI
AI-powered engineering assistant for university students.
Built with React + Vite + TypeScript + Tailwind CSS + NVIDIA NIM + Supabase.

## Setup
1. Clone the repo
2. Run `npm install` 
3. Copy `.env.example` to `.env.local` and fill in your keys
4. Run `npm run dev` 

## Environment Variables
- VITE_NVIDIA_API_KEY - NVIDIA NIM API key
- VITE_SUPABASE_URL - Supabase project URL  
- VITE_SUPABASE_ANON_KEY - Supabase anon key

## Deployment
Deployed on Vercel. Add environment variables in Vercel dashboard.
